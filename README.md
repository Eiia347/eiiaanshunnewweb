# 在地 · 安顺／镇宁

> 一个只做信息收集、不做交易的在地知识库。
> 用 Agent 从公开来源提取结构化事实，以「可追溯的重述」呈现安顺与镇宁的吃穿风景建筑人文地理。
> **入口沉浸，阅读安静，出处永远可见。**

---

## 运行

```bash
npm install
npm run dev        # 开发：http://127.0.0.1:5173
npm run build      # 产物写入 dist/
npm run preview    # 预览构建产物：http://127.0.0.1:4173
```

无后端、无数据库、无构建期请求。数据是仓库里的三个 JSON 文件，前端 `import` 后静态渲染。

全部为 hash 路由（`src/lib/hooks.js` 的 `parseHash`），刷新不 404，可直接分享。

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `#/` | 入口 Hero | 全屏沉浸 + 向下滚动进入嵌入式地图与三条线索 |

## 数据

```
src/data/raw/batchA.json   13 条  A1–A13  安顺主线（屯堡、地戏、喀斯特与赛事）
src/data/raw/batchB.json    7 条  B1–B7   市井安顺（街道、湖、早市、茶馆、动线）
src/data/raw/batchC.json   16 条  C1–C16  镇宁专栏（九章节）
src/data/kb.js             归一化 + 派生索引
src/data/SCHEMA.md         字段契约
```

`kb.js` 在导入时统一做 `normalize()`：补齐默认值、把 `entry_no` 强制成字符串（`C{n}`）、建立 `BY_ID` / `GROUPS` / `LAYERS` / `CHAPTERS` 索引，并派生出 `TOTAL` 统计与 `statsOf` / `worstTier` / `chapterEntries` 等函数。页面不直接读 JSON，只读 `kb.js`。

### 等级（可追溯性）

| 等级 | 含义 |
| --- | --- |
| `A` | 权威来源直述：政府/学术/机构/主流媒体原文可核对 |
| `A/B` | 核心断言为 A 级，含少量 B 级或并置说法 |
| `B` | 单一可靠媒体或机构页面，无第二来源互证 |
| `C` | 来源薄弱、仅为自媒体/百科，或用户指定的现场节点 |

等级只表示**来源强度**，不表示事实真伪的最终裁决。界面用边框形状编码等级，不用颜色——颜色留给地理类别：A 实心细边框 / B 无边框 / C 虚线边框。

### 校验

```bash
node tools/validate-kb.mjs
```

校验字段完整性、编号连续性、坐标范围、来源 URL 与断言引用闭合。当前结果：

```
条目 36/36 · A 13 · B 7 · C 16
等级分布 { A: 6, 'A/B': 9, B: 10, C: 11 }
来源 121 · 断言 197
✓ 全部通过
```

## 设计

### 入口沉浸，阅读安静

- **Hero**：纯 CSS 的层叠山脊（SVG data-URI）+ 颗粒 + 两盏模糊暖灯 + 缓慢浮动关键帧。零图片请求——不是因为懒，是因为来源图片未逐张确认授权，`hero_media.type: "none"` 是合法且默认的状态。
- **首页向下**：滚动进入嵌入式地图与三条线索卡片（A 安顺主线 / B 市井安顺 / C 镇宁专栏），每条标注「N 条 A 级及以上」。
- **镇宁专栏**：九章节纵向滚动，每章一个巨型汉字做背景字形，配 `--p` 滚动进度变量做极轻的位移（约 26px，非视差表演）。章节文字与条目卡片用 IntersectionObserver 逐次显现。
- **条目详情**：**不使用任何滚动视差**。详情页的任务是让人读完，动效只保留入场淡入。

### 出处永远可见

这是整个站点的核心承诺，落成三处常驻 UI：

1. **出处条（srcbar）**——固定停在视口底部，像音频播放器的进度条：左边是当前章节/点位，中间是等级与计数，右边是「展开原文」。它随阅读位置更新，**不随内容滚出视口，也不被任何动效遮挡**。展开后是本章节去重后的完整来源列表（按等级排序，标注被哪些条目引用）。
2. **右侧出处栏（条目页）**——sticky，独立滚动。断言后的 `[src_id]` 按钮点击即定位并高亮对应来源卡片。
3. **内联原文**——每条断言旁「展开原文」，把 `sources[].excerpt` 直接展开在断言下方，不跳转、不离开阅读位置。来源页 404 也不影响这段关键句的可读性。

### 地图

Leaflet + Esri World Dark Gray Canvas（CARTO 的 `dark_all` 会在瓦片上打 "API KEY REQUIRED" 水印，已弃用）。CSS `filter: sepia/hue-rotate/brightness` 把灰调压成蓝黑，与站点底色接上；瓦片连续失败 4 次后加 `.map--offline`，退化为无底图的点线画布而不是空白。

标记用 `divIcon`：形状编码等级，颜色编码类别，当前点位琥珀色发光。动线在 `#/explore` 画折线，在 `#/route/:id` 随滚动进度逐段绘制（`stroke-dasharray` 推进）。

## 数据诚实性：删掉了什么

这些是刻意的取舍，不是遗漏：

- **A10 安顺马拉松**——全库最弱一条，仅一份地市级媒体稿件支撑，等级 B，页面明确标注。
- **A5 洗布河**——无法核实，已从条目中删除，不再作为事实出现。
- **C3 张万全**——与「泥人张」同名混淆，已把叙述重心从人名移到「脸子」工艺本身。
- **C4 长脚寨布依族地戏**——论文全文不可获取，降级为索引条目，只记录「存在这篇论文」并标注未获取全文。
- **C7 潘祖文与马厂村苗银**——单一自媒体来源，无支撑的细节全部删除，等级 C。
- **C8 镇宁地戏村落分布**——四村名单无来源，不列。
- **C16 蜂糖李采收时序**——用户提供的 2026 年采收日期无来源，只引用 2023 年错峰上市序列并注明。
- **C13 / C14 下北街、唸佛寺、老粮仓**——无独立文献，作为用户指定的现场节点保留，标注说明并给出近似坐标。
- **C1「四落腔」**——无来源，不作为断言主张。

### 并置而非裁决：C15 蜂糖李

全站最能说明方法的一条。同一件事的两种叙述被平行放在页面上，不合并、不裁决：

- **民间传说**（光明网，B 级）：母本树上蜂巢溢蜜、蜜顺树干入根，果实甜如蜂蜜。
- **科研记载**（省农业农村厅，A 级）：品种来源、产地条件、栽培数据。

产业数据按年份分开成独立断言，**绝不混算**：2026 年（22.01 万亩 / 挂果 18.2 万亩 / 7.7 万吨 / 综合产值预计 37 亿元，中国日报 2026-06-11）与 2025 年（17.6 万亩 / 6.75 万吨，新华网）各自成立，页面注明「两组数字分年并列，不可混用」。

## 边界与已知限制

- **不部署后端。** 数据为整理后导出的静态 JSON，前端直接加载。
- **不提供图片。** `hero_media` 与来源图片均需逐张版权确认；未确认时 `media_type: "none"` 是合法状态。全站零照片是设计决定。
- **学术论文无法获取全文时降级为索引条目**，只记录「存在这篇论文」，标注来源未获取全文。
- **来源失效时仍可展示关键句**：`sources[].excerpt` 存原文关键句，出处卡片不因页面 404 而失去意义。
- **仍需人工核验**：数字、年份、专名写法、URL 可访问性、等级匹配度。
